# text-autocomplete
Автодополнение текста на основании модели LSTM и сравнение с моделью GPT2
Ввиду ограниченных вычислительных возможностей - сравнение проводилось на огранченнй выборке из Sentiment 140 (scv в папке data\).

Итоги: значение Rouge-L для выборки из 1000 кейсов были в разы ниже чем Rouge-L после 3 эпох обучения на сокращенном dataset-е.
Обучение модели показывало последовательное уменьшение функции ошибки и постоянное увеличение ROUGE.

РЕКОМЕНДАЦИЯ: использовать LSTM, хорошо показала себя при обучении на малой выборке при высоких значениях ROUGE.

Метрик:
Модель	ROUGE-L	Обучение
LSTM	0.21	2 эпохи	
GPT2	0.043	предобученная

В файлах solution.ipynb - обучение и получение ROUGE для модели LSTM, в файле transformer_rouge.ipynb - вычисляется ROUGE для модели GPT2
